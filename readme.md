# LazyVim Termux

A simple script to install and configure LazyVim in Termux.

## Installation

To install, run the following command in Termux:

```
curl -sL https://raw.githubusercontent.com/nt-portal/LazyVim-Termux/main/install.sh | bash
```

## Features

- Automatic backup of existing config.
- Installs LazyVim starter.
- Custom font setup.
- WakaTime plugin included.
- Markview plugin included.
- Noice plugin disabled for performance.
